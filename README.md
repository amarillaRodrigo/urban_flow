
# Urban Flow

## Sprint 1

### Objetivo
Aplicar los conocimientos adquiridos para el versionado de código, la 
organización, limpieza del código y la utilización de pandas.

### Introducción y Contexto del problema
La localidad de Vaalserberg de Bélgica cuenta con un sistema de radares 
urbanos para la detección de infracciones por exceso de velocidad. Los 
registros históricos provienen de sistemas heredados que presentan errores de 
formato y faltante de datos, generando registros inconsistentes en el nuevo 
sistema. El objetivo es analizar y depurar estos datos para obtener 
información relevante y asegurar una integración sin inconsistencias en el 
futuro.
